選び方の整理

見るところは4つあります。

  1. 手動か電動か — 手動はグリップを回す分だけ手間がかかる代わりに安く、電動は回す手間が減る代わりに価格が上がり、充電や電池が要る。ネジの数が少ない家庭用なら、手動で足りるかどうかが分かれ目になる
  2. ビットの種類と本数 — 「25in1」「138in1」「47点」「30ビット」など数字の意味が出品ごとに違う。トルクスや六角といった特殊ネジに対応するかを商品名で確かめたい
  3. 用途の大きさ — 商品名に「精密」とあるものは時計・メガネ・小型家電向けの細いビット中心。「18V」「最大50N.m」とあるものは組み立てや締め付けまで想定した大きめのタイプ
  4. 価格とレビュー実績 — 今回は¥1,190〜¥4,980。レビューは62〜360件で、評価は★3.68〜4.74
